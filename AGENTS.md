# Flutter Project Rules

- Reuse existing shared widgets before creating new ones.
- Use ColorManager, StylesManager, Assets, Dimensions.
- Never use Material widgets if an equivalent custom widget exists.
- Follow feature-first architecture.
- Keep widgets small.
- Keep files under 50 lines unless splitting hurts readability.
- Run flutter analyze after every change.
- Never modify unrelated files.
- Show diff before applying.
